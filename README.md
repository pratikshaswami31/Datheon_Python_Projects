Project Overview

This repository contains Python projects developed as part of the Datheon Python for Data Engineering program.

Task 1: Autonomous Web Scraper & Data Extractor

This task uses Python, Requests, and BeautifulSoup to extract book details from a practice website.

Features

- Extracts book titles, prices, ratings, and availability.
- Handles multiple pages using pagination.
- Exports the collected data into CSV and JSON files.

Technologies Used

- Python
- Requests
- BeautifulSoup4
- CSV
- JSON

How to Run

1. Install the required libraries:
   
   python -m pip install requests beautifulsoup4

2. Run the program:
   
   python web_scraper.py
